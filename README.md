# Hi-Optimizer
A powerful Windows 10/11 optimization script focused on performance, debloating, gaming, memory optimization, and system tuning.
# 🚀 HI+ Optimizer 

HI+ Optimizer is an advanced Windows optimization script designed to improve system performance, reduce background processes, free memory, and remove unnecessary Windows components.

> ⚠️ This project is intended for advanced users. It makes system-level changes and should be used carefully.

---

## Features

### ⚡ CPU Optimization
- Performance registry tweaks
- Scheduler optimizations
- Power plan tweaks

### 🎮 GPU Optimization
- NVIDIA optimization
- AMD optimization
- Intel optimization

### 🧹 System Debloat
- Remove unnecessary Windows apps
- Disable telemetry
- Reduce background processes

### ⚙️ Services Optimization
- Disable unnecessary services
- Gaming-focused service configuration

### 🌐 Network Optimization
- TCP/IP tweaks
- Network latency improvements
- Internet performance optimizations

### 💾 RAM Optimization
- Memory management tweaks
- Cache optimizations

### ✨ Extras
- Latency tweaks
- Advanced performance tweaks
- Additional gaming optimizations

---

## Safety Features

- Create System Restore Point
- Registry Backup
- Administrator privilege check

---

## Requirements

- Windows 10 or Windows 11
- Administrator privileges

---

## How to Use

1. Download the project.
2. Right-click `HIOptimizer.bat`.
3. Select **Run as Administrator**.
4. Create a restore point when prompted.
5. Choose the optimization category from the menu.

---

## Warning

This tool modifies Windows settings including the registry, services, boot configuration, and networking.

Always create a restore point before applying tweaks.
